# **App Name**: LED Estimate Pro

## Core Features:

- LED Screen Configurator: Allows users to configure the height and width of LED screens using sliders. The maximum dimensions for both height and width is 30 meters.
- Real-time Quotation: Dynamically updates the price quote as the user adjusts the dimensions and selects products. Calculates in real-time, based on adjustable backend values.
- Product Selection: Enables the user to select from a dropdown list of available LED screens, with pre-configured height and width, automatically applying the selected product's values to the quotation.
- Indoor/Outdoor Selection: Allows users to select between indoor and outdoor LED screens.
- Visual Preview: Presents a silhouette of a person with a ladder and an LED screen that dynamically scales according to the height and width values the user has set.
- Backend Admin: A password protected admin area to modify product pricing and other related values.

## Style Guidelines:

- Primary color: Deep blue (#293462) to evoke a sense of professionalism and trust, like broadcast media. 
- Background color: Light gray (#E8E8E8) to provide a neutral and clean backdrop.
- Accent color: Electric purple (#806491) for highlights and interactive elements, contrasting the primary color to draw the user's eye.
- Body and headline font: 'Inter', a grotesque sans-serif for a clean and modern aesthetic, suitable for both headlines and body text.
- The configurator should feature a split-screen layout with the configuration settings on one side and a visual preview on the other.
- Subtle transitions and animations will be used when the quotation is updated or a new product is selected.
